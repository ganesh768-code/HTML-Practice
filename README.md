

# 📘 HTML Practice Repository

*This repository contains **my personal HTML practice files**, created while learning core HTML concepts from the book
“HTML & CSS: Design and Build Websites” by Jon Duckett.*
*All examples were written by me to understand and apply HTML fundamentals, not to copy the book’s code.
This repository focuses only on HTML (chapter-wise practice) and is intended for learning and job-portfolio purposes.*

The files are **committed in learning order**, starting from basic page structure and moving toward advanced forms and extra markup.
